# API Controllers NovaTech
Ce dossier contient les contrôleurs API REST.
- AuthController.php : Auth Sanctum (login, logout, register, me).
- ServiceController.php : CRUD services.
- DevisController.php : CRUD devis.
- BlogController.php : CRUD blog.
- ProjetController.php : CRUD projets.
- MarketplaceController.php : CRUD marketplace.
