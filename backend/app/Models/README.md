# Models NovaTech
Ce dossier contient les modèles Eloquent pour le projet NovaTech.
- User.php : Modèle utilisateur avec gestion des rôles.
- Role.php : Gestion des rôles dynamiques.
- Service.php : Services numériques proposés.
- Devis.php : Demandes de devis clients.
- Blog.php : Articles du blog.
- Projet.php : Projets des développeurs.
- Produit.php : Produits de la marketplace.
